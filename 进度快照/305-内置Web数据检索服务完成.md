## 具体修改

### 新增模块

- `dit-tools-src/cinevault-pro/src/application/websearch/WebSearchService.h`
- `dit-tools-src/cinevault-pro/src/application/websearch/WebSearchService.cpp`

提供：

- `GET /`
- `GET /index.html`
- `GET /styles.css`
- `GET /app.js`
- `GET /api/health`
- `GET /api/search?q=关键词&limit=数量`

### Web 页面

- `dit-tools-src/cinevault-pro/resources/websearch/index.html`
- `dit-tools-src/cinevault-pro/resources/websearch/styles.css`
- `dit-tools-src/cinevault-pro/resources/websearch/app.js`

页面首屏移除了搜索框上方文字，只保留中心搜索框；支持浅色/暗黑模式自动适配、液态玻璃质感和搜索框长投影。

### 代码前后对比

修改前：软件没有局域网 Web 搜索服务，快捷搜索只在 Qt/QML 窗口内使用。

修改后：`AppContext` 持有并启动 `WebSearchService`：

```cpp
m_webSearchService(new WebSearchService(m_materialCenterQueryService, this))
```

```cpp
if (m_webSearchService->start(17890, &webSearchError)) {
    Logger::info(QStringLiteral("web_search_service_started urls=%1")
                     .arg(m_webSearchService->localAccessUrls().join(QStringLiteral(","))));
}
```

修改前：CMake 未包含 Web 搜索资源与测试。

修改后：CMake 增加 Web 搜索源码、资源和 `WebSearchServiceTest`。

修改前：`VERSION` 为 `0.1.189`。

修改后：`VERSION` 为 `0.1.190`。
