# 321 - 素材中心解析迁移 filmstoryboard 规则

- 时间：2026-08-03
- 当前模块：素材管理中心视频解析（设置、抽帧、帧级视觉解析）

## 已完成

1. 设置页替换为 filmstoryboard 的四种抽帧策略：逐帧、场景变化 + 间隔补帧、固定间隔、高保真采样。
2. 新增并持久化抽帧间隔（秒）、场景阈值、最低清晰度；旧的按帧号模式与联系表补帧设置不再参与新视频解析。
3. `FFmpegAdapter` 改为单条 FFmpeg 过滤链抽取候选帧：场景变化策略使用 `select=eq(n,0)+gt(scene,threshold)+gte(t-prev_selected_t,interval)`，其余策略与 filmstoryboard 对齐。
4. 候选帧增加清晰度、曝光和 64 位感知哈希去重筛选，仅保留合格帧进入视觉解析。
5. 帧级视觉提示词改为 filmstoryboard 的 22 个镜头字段，包含画面细节、人物/道具、动作趋势、运镜、景别、构图、朝向/视线、动作阶段、空间与时间线索、机位、焦点、光色、叙事功能和剪辑承接。
6. 为兼容既有素材中心数据表和界面，上述字段被映射保存到既有的标题、标签、对象、动作和场景字段；旧的实体/OCR JSON 不再是新解析契约。
7. 新采样计划版本为 `filmstoryboard_candidate_sampling_v1`；恢复解析按已保存的候选帧续跑，不再按旧帧号规则补帧。

## 关键前后对比

- 修改前：先读取视频全部帧号，按“每 10 帧/逐帧/自定义帧号间隔”与联系表帧号选取，再逐张定位抽图。
- 修改后：FFmpeg 按场景变化和时间间隔直接生成候选帧，随后筛除模糊、曝光异常与重复画面；高保真模式将间隔限制为 0.1–0.25 秒。

- 修改前：帧级视觉结果为 caption、tags、objects、actions、setting、实体和 OCR。
- 修改后：请求并解析 filmstoryboard 的 22 项分镜维度；现有展示层将其以带字段名前缀的标签/动作/场景组合展示与检索。
