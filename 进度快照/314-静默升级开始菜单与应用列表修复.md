## 问题与根因

自动更新使用 Inno Setup 的静默安装模式。现有安装器把程序组快捷方式和卸载注册表完全交由安装器默认过程处理；一旦静默路径、历史安装状态或快捷方式任务状态异常，应用文件仍在安装目录，但开始菜单和 Windows 应用列表可能没有可发现入口。

项目已有的安装器启动测试使用 `/NOICONS` 模拟该类入口丢失情况，但此前没有验证恢复结果。

## 修改内容

文件：`installer/windows/cinevault.iss`

### 之前

```ini
DefaultDirName={autopf}\影资管家
DefaultGroupName=影资管家
DisableProgramGroupPage=yes
```

安装完成后只依赖 `[Icons]` 与 Inno Setup 的默认卸载注册表写入。

### 之后

```ini
UninstallDisplayName=影资管家
UsePreviousAppDir=yes
UsePreviousGroup=yes
CreateUninstallRegKey=yes
```

并在 `ssPostInstall` 增加 `EnsureApplicationEntries()`：

- 强制创建 `{group}\影资管家.lnk` 和 `{group}\卸载影资管家.lnk`；
- 主快捷方式的目标、工作目录和图标均指向新安装目录的 `CineVault.exe`；
- 回填固定 `AppId` 对应卸载键的 `DisplayName`、`DisplayVersion`、`InstallLocation`、`DisplayIcon`、`UninstallString` 和 `QuietUninstallString`；
- 保留 Inno Setup 作为卸载键所有者，只在每次升级结束时修复入口字段。

Windows 的卸载键路径由稳定的 AppId 决定：

```text
HKLM\Software\Microsoft\Windows\CurrentVersion\Uninstall\{F3C5C6D6-8B77-4F6A-9F6B-9EA5B6D6AA21}_is1
```

文件：`tool/test_installer_startup.ps1`

新增静默安装断言：即便传入 `/NOICONS`，也必须存在两个开始菜单快捷方式，主快捷方式必须指向测试安装目录的 EXE，且卸载注册表必须包含正确显示名、安装目录和卸载命令。
