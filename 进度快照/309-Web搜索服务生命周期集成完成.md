## 已完成内容

### 1. 软件启动时自动启动 Web 搜索服务

当前 `AppBootstrap::run()` 在 QML 根对象加载成功后调用 `AppContext::startInteractiveServices()`；其中启动 `WebSearchService`：

```cpp
if (m_webSearchService->start(17890, &webSearchError)) {
    Logger::info(QStringLiteral("web_search_service_started urls=%1")
                     .arg(m_webSearchService->localAccessUrls().join(QStringLiteral(","))));
}
```

服务监听 `AnyIPv4`，因此支持：

- 本机 `http://127.0.0.1:17890/`
- 当前局域网 `http://192.168.0.24:17890/`

### 2. 软件退出时主动释放端口

修改文件：

- `dit-tools-src/cinevault-pro/src/app/AppContext.cpp`

新增两层停止保障：

1. Web 服务启动成功后绑定 `QCoreApplication::aboutToQuit`，Qt 开始退出时立即调用 `stop()`。
2. `AppContext::~AppContext()` 进入关闭屏障前再次调用 `stop()`，保证端口不等待后台任务完成才释放。

`WebSearchService::stop()` 本身幂等，重复调用安全。
