## 已完成内容

### 1. 更新链安全与可靠性（P0-02、P1-08、P1-09、P2-08）

修改前：

- 安装包与 Release 缺少端到端 SHA-256 约束；
- 待安装文件边界和重解析点检查不足；
- 代理失败可能隐式降级；
- 缺少自动更新、手动更新、禁止更新三态完整契约。

修改后：

- 安装包名、Release digest 和本地 SHA-256 全链校验；
- 只信任 GitHub HTTPS/CDN 来源，防止待安装路径越界与重解析点绕过；
- Authenticode 签名者指纹由 `CINEVAULT_UPDATE_SIGNER_SHA256` 编译注入，缺失时拒绝自动安装；
- 严格代理模式、续传、重试、磁盘空间检查和缓存清理已补齐；
- 三种更新策略已接入设置和启动流程。

### 2. 跨项目任务隔离与异步生命周期（P1-01 至 P1-05）

- 后台扫描、媒体、元数据、素材和视频任务在启动时捕获原始项目数据库路径；
- 同步信号携带原始项目上下文，不再被后续项目切换污染；
- 媒体恢复去重键改为“项目 + 根目录”；
- 服务析构和 `AppContext` 销毁顺序会等待已发起的后台任务；
- 项目记录使用事务，引入 `.cinevault-project` 标记，删除只能作用于精确标记的项目目录；
- 打开、重命名、移动与物理根目录修复均具有回滚路径。

### 3. 扫描中断和局部访问失败（P1-06）

修改前：中断扫描可复用污染代次，不可访问子树可被当成删除。

修改后：

- 中断后使用新扫描代次；
- 根目录不可访问时整体失败；
- 子目录不可访问时警告并把旧子树复制到新 staging，不误删历史记录。

### 4. 秘钥与远程视觉端点（P1-13）

- 新增 Windows Credential Manager 封装，Vision API Key 从明文设置迁移到系统凭据库；
- 远程端点只允许 HTTPS，仅本机回环调试允许 HTTP；
- 重定向不允许降级到不安全协议。

### 5. 智能搜索可靠性与交互（P1-07、P2-02、P2-03）

- 响应上限提高到 768 tokens，错误日志只记录状态、字节数、`finish_reason` 和摘要；
- 仅允许一次受控 JSON 修复请求；
- A→B→A 查询在异步返回时会先按真实 key 入缓存，不再因当前查询变化丢失 A 的有效结果；
- GPU 探测、停止和重启已改为异步状态机，主线程操作受测试约束为 200 ms 以内；
- 真实 GPU 集成测试已扩展为 3 种查询、每种 20 轮。

### 6. 任务持久化（P2-04）

- 数据库 schema 从 6 升到 7；
- `job` 表新增 `subject_json` 和 `progress_context_json`；
- 主体、进度上下文和后台项目上下文完整序列化；
- 数据库写失败时回滚内存状态并发出 `persistenceError`；
- 重启加载上限 500 条，SQL 错误不再被当成空结果。

### 7. QML 静态警告（P2-05）

已修复已知的 incompatible-type、layout 和 missing-property 问题，并新增 `tool/check_qml_warnings.ps1`。该脚本的干净云端生成目标是：

- 总警告数不高于 731；
- incompatible-type、layout、missing-property 三类为 0；
- 后续需补上 `type == error` 的硬失败条件并接入 CI。

### 8. 日志模块当前修改（P2-06，进行中）

修改前：

```cpp
QFile file(logFilePath);
file.open(QIODevice::WriteOnly | QIODevice::Append | QIODevice::Text);
file.write(line);
```

- 全局路径缺少并发保护；
- 每条日志重新打开文件；
- 无大小上限、无轮转；
- 项目切换会重定向全局日志，存在后台任务被记录到错误项目的后果。

修改后：

```cpp
QMutexLocker locker(&state.mutex);
if (state.file.size() + line.size() > kMaxLogFileBytes) {
    rotateLocked(state);
}
state.file.write(line);
```

- 日志改为全局 `Paths::logsRoot()/app.log`；
- 持久打开的 `QFile` 由 `QMutex` 串行化写入；
- 单文件最大 5 MB，保留 `.1` 至 `.3` 三份备份；
- 单条消息最大 256 KiB，防止异常大消息撑爆日志；
- Qt/QML warning/critical 按级别进入同一日志；
- `ProjectService` 不再于项目打开/恢复时重新初始化全局 Logger。
