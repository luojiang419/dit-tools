# 276 - 更新窗口动态百分比与详情展示完成

## 本轮目标

修复独立更新器窗口的进度呈现：百分比不再直接从一个真实采样点跳到下一个采样点，并增加持续更新的安装详情，避免用户在等待旧版本退出或安装器较长阶段时误以为程序卡死。

## 已完成内容

### 1. 真实目标值驱动的动态百分比

修改前：

```cpp
m_progressBar->setValue(event.percentage);
m_percentageLabel->setText(QStringLiteral("%1%").arg(event.percentage));
```

收到 10、20、30 等采样点时，界面直接跳值。

修改后：

```cpp
m_progressAnimation->setStartValue(m_displayedPercentage);
m_progressAnimation->setEndValue(target);
m_progressAnimation->start();
```

- 使用 `QVariantAnimation` 从当前显示值平滑过渡到最新真实目标值；
- 只追赶安装器已经报告的值，不使用会自行超前的假进度定时器；
- 新目标到达时从当前显示值重新衔接；
- 百分比保持单调，不倒退；
- 错误时立即停在真实失败百分比；
- 成功时动态到达 100%。

### 2. 等待旧版本期间持续刷新

修改前：

```cpp
emitProgress(1, 5, "关闭旧版本", "正在等待旧版本退出...");
```

最长等待120秒期间只有一次5%事件。

修改后：

- 每500毫秒检查旧PID；
- 每秒发送一次可见详情：`已等待 N 秒 · 正在检查 PID X`；
- 确认旧版本退出后真实推进到8%；
- 随后再启动独立安装程序。

### 3. 更新详情面板

窗口新增只读 `QPlainTextEdit`：

- 标题为“更新详情”；
- 每条记录包含本地时间、步骤、主消息和子步骤；
- 自动滚动到最新记录；
- 最多保留120个文本块，避免无限增长；
- 重复内容不重复追加；
- 安装失败后详情继续保留，便于用户判断失败位置。

详情内容包括：

- 准备独立更新器；
- 旧版本PID与等待秒数；
- 旧版本退出确认；
- 安装包文件名、大小和目标目录；
- Inno Setup 实际安装百分比；
- 映射后的总进度目标；
- 启动新版、成功或错误信息。

### 4. 保留真实安装进度契约

- `installer/windows/cinevault.iss` 的 `CurInstallProgressChanged` 保持不变；
- 进度继续通过 `/UPDATEPROGRESSFILE=` 写入实际安装器百分比；
- `UpdaterSessionRunner` 仍以150毫秒轮询真实进度文件；
- 实际安装器 `0–100%` 仍映射到总进度 `10–90%`；
- 95% 和100%分别只在安装完成、启动新版成功时出现。

## 测试与静态检查

新增源码契约锁定：

- 必须使用 `QVariantAnimation`；
- 必须以当前显示值为动画起点，以真实目标为终点；
- 必须存在更新详情面板；
- 必须显示等待秒数和安装器实际百分比；
- 禁止恢复 `setValue(event.percentage)` 直接跳值；
- 禁止改成无限不确定进度条 `setRange(0, 0)`。
