### 模块 1：扫描器固定批次流式化

修改 `src/core/scan/ScanEngine.h/.cpp`：

- `CurrentScanVersion` 从 4 增至 5（这是扫描目录契约版本，不是应用发布版本）。
- 单目录枚举容器固定为 256 条。
- 每 256 条独立事务写入 `scan_stage_asset`、`scan_stage_folder` 和 `scan_work_item`。
- 最终批次完成后才把当前目录工作项标记为 `completed`。
- 中断恢复时先清理未完成目录的直接素材、直接子目录及对应待处理工作项，然后幂等重枚举。
- 扫描阶段不再对每个文件调用 `QFile::open()`；仅保存目录项可读属性，真实解析能力交给后处理服务。
- 每批检查：用户取消、素材源是否在线、项目盘是否至少剩余 1 GiB。
- 新增 `requestCancel(sourceRootId)`；取消保留扫描会话，重试可继续。
- `std::bad_alloc`、标准异常和未知异常均在工作线程边界内转换为可恢复失败。

同一 10 万单层目录优化后结果：

关键对比：

```text

修改后：单层 10 万文件 -> 队列峰值 256，私有内存峰值约 6.4 MiB。
```

新增扫描回归：

- 跨越 256 边界后注入中断，确认只保留已提交暂存批次、旧正式索引不发布。
- 中断期间删除第一批中的文件并新增文件，重试后无旧文件残留、总数正确。
- 请求取消后保留一个恢复会话，第二次扫描能完整完成。
- 锁定文件测试改为验证轻量索引不逐文件打开，扫描状态保持 `ok`。

### 模块 2：后处理 Keyset 分页

修改 `MetadataExtractionService`：

- 删除 `startForSourceRoot()` 在 UI 调用线程全量加载待处理 `AssetFile` 的逻辑。
- 后台连接先执行 `COUNT(*)` 获取近似总量。
- `fetchPendingAssets()` 改为：

```sql
WHERE af.id > :lastId
ORDER BY af.id
LIMIT 128
```

- 每页 128 条，再按 32 条调用 ExifTool；每页完成即释放。
- 指标队列名：`metadata.exif_assets`。

修改 `MediaTaskService`：

- `fetchAssets()` 增加 `lastAssetId` 与 `limit`。
- 缩略图和 FFprobe 分别按 `af.id > :lastId ORDER BY af.id LIMIT 128` 读取。
- `runThumbnailJob()`、`runMetadataJob()` 不再接收整源 `QVector`，自行循环分页。
- 指标队列名：`media.thumbnail_assets`、`media.ffprobe_assets`。

新增分页回归：

- 129 个真实 JPEG 经 ExifTool 分页后全部落库，峰值队列为 128。
- 300 个素材经缩略图分页后全部成功，峰值队列为 128。

## 具体代码前后对比

### 扫描器

修改前：

```cpp
QVector<DirectoryEntry> directoryEntries;
while (entryIterator.hasNext()) {
    directoryEntries.append(readEntry());
}
db.transaction();
for (const auto &entry : directoryEntries) {
    writeEntry(entry);
}
db.commit();
```

修改后：

```cpp
constexpr qsizetype ScanEnumerationBatchSize = 256;
QVector<DirectoryEntry> directoryEntries;
directoryEntries.reserve(ScanEnumerationBatchSize);
while (entryIterator.hasNext()) {
    directoryEntries.append(readEntryWithoutOpeningFile());
    if (directoryEntries.size() == ScanEnumerationBatchSize) {
        commitDirectoryBatch(directoryEntries, false);
        directoryEntries.clear();
    }
}
commitDirectoryBatch(directoryEntries, true);
```

### ExifTool/缩略图/FFprobe

修改前：

```cpp
const auto assets = fetchAllPendingAssets(sourceRootId);
for (const auto &asset : assets) {
    process(asset);
}
```

修改后：

```cpp
qint64 lastAssetId = 0;
while (true) {
    const auto assets = fetchPendingAssets(sourceRootId, lastAssetId, 128);
    if (assets.isEmpty()) break;
    lastAssetId = assets.constLast().id;
    processAndReleasePage(assets);
}
```
