## 问题

报表导出项此前直接使用 Qt 默认 `CheckBox`，其浅色背景和浅色文本在当前主题面板内对比不足，阅读困难。

## 修改

文件：`dit-tools-src/cinevault-pro/src/ui/qml/workspaces/ReportWorkspace.qml`

新增本地 `ReportSectionOption` 主题化组件，并替换 8 个报表选项。

### 修改前

```qml
CheckBox {
    text: "视频元数据明细"
    checked: viewModel && viewModel.reportSectionEnabled("videoMetadata")
}
```

### 修改后

```qml
ReportSectionOption {
    text: "视频元数据明细"
    section: "videoMetadata"
}
```

组件统一使用：

- 未选中：`Theme.inputBg`、`Theme.line`、`Theme.text`；
- 选中：`Theme.selectedBg`、`Theme.selectedLine`、`Theme.primaryBg`；
- 勾选：`Theme.primaryText` 的高对比白色标记；
- 禁用：降低整体透明度并使用 `Theme.weak`。

因此深色、浅色和跟随系统主题均由既有 `Theme.qml` 自动适配。
