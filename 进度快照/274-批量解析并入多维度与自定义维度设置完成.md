# 274 - 批量解析并入多维度与自定义维度设置完成

## 本轮目标

重组素材管理中心解析入口：将原“批量解析”能力并入“多维度解析”，用补充解析/全部重新解析策略弹窗替换旧维度勾选弹窗；把五个内置维度明确纳入常规解析；在设置页增加可持久化的自定义解析维度管理，并让自定义维度自动衔接常规解析任务。

## 已完成内容

### 1. 解析入口合并

- 删除素材中心顶部独立“批量解析”按钮。
- 将“全局多维度解析”统一为“多维度解析”。
- 点击后始终打开“选择多维度解析方式”弹窗。
- 弹窗保留两种策略：
  - 补充解析：补齐结构化字段、自定义维度，并继续处理待解析/失败素材；
  - 全部重新解析：清理旧解析产物后从头解析，再自动执行自定义维度。
- 删除旧 `dimensionAnalyzeDialog`、临时 `dimensionDraftModel`、维度复选列表和素材中心临时新增维度输入框。

修改前：

```qml
ActionButton { text: "批量解析" }
ActionButton {
    text: "全局多维度解析"
    onClicked: dimensionAnalyzeDialog.open()
}
```

修改后：

```qml
ActionButton {
    text: "多维度解析"
    onClicked: multiDimensionAnalyzeDialog.open()
}
```

### 2. 内置维度并入常规解析语义

以下五项不再作为临时勾选项出现，设置页明确标记为“已并入常规解析”：

- 色彩风格；
- 构图与镜头语言；
- 品牌/文字线索；
- 适用场景；
- 情绪氛围。

素材详情中独立维度结果区域更名为“自定义维度分析”，避免和常规结构化结果混淆。

### 3. 自定义解析维度持久化

- `AppSettings` 新增 `customAnalysisDimensions`。
- 存储键：`materialCenter/customAnalysisDimensions`。
- 规则：去除首尾空白、忽略大小写去重、单项最多 32 字符、最多 20 项。
- 空列表会删除设置键，避免残留无效配置。
- `SettingsViewModel` 新增读取、添加、删除接口。
- 内置五项禁止重复添加，并给出“已包含在常规解析任务中”的提示。

### 4. 设置页磨砂玻璃维度管理

- 视觉解析设置区新增“自定义解析维度”按钮和当前数量提示。
- 点击后打开响应式管理弹窗。
- 弹窗包含：
  - 已并入常规解析的五个只读磨砂胶囊；
  - 自定义维度输入和添加按钮；
  - 空状态提示；
  - 可悬停、可删除的磨砂玻璃胶囊按钮；
  - 深色/浅色主题背景适配；
  - 小窗口宽高安全收缩和滚动支持。

### 5. 常规任务自动衔接自定义维度

- 图片、视频、文档常规解析成功后，自动读取当前自定义维度并排入维度队列。
- 单帧失败重试不会重复触发整套自定义维度。
- 补充解析遇到结构化字段已完整的素材时，会继续检查自定义维度：
  - 有缺失则排入维度队列；
  - 全部完成才真正跳过。
- 全部重新解析完成后自动补跑自定义维度。
- 常规解析队列优先完成，维度队列随后串行执行，避免并发处理同一素材。

修改前：

```cpp
if (!hasVisualGap) {
    ++alreadyComplete;
    continue;
}
```

修改后：

```cpp
if (!hasVisualGap) {
    if (enqueueConfiguredDimensionsIfNeeded(normalizedKey, &rejection)) {
        ++accepted;
        continue;
    }
    ++alreadyComplete;
    continue;
}
```

常规任务完成衔接：

```cpp
if (succeeded && completedJob.mode != AnalysisRunMode::SingleFrame) {
    enqueueConfiguredDimensionsIfNeeded(videoKey, &ignoredError);
}
```
