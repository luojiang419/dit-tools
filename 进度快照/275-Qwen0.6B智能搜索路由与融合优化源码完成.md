# 275 - Qwen 0.6B 智能搜索路由与融合优化源码完成

## 本轮目标

继续使用 `Qwen3-0.6B-Q8_0.gguf`，把原来所有内容查询都调用模型的策略升级为首轮即时搜索、智能路由、查询计划 V2、多路召回、加权 RRF 融合和搜索意图驱动的运行时管理。

## 已完成内容

### 1. 智能查询路由

新增 `SearchAssistantRouter` 和三态决策：

- `Skip`：确定性、精确查找或高可靠直接证据；
- `ReadyOnly`：可靠性灰区，仅使用热模型；
- `Required`：无结果、多实体、关系、否定、并列或低可靠查询。

修改前：

```cpp
// 所有稳定非空内容查询都进入模型调用。
startSearchUnderstanding(m_lastParsedQuery);
```

修改后：

```cpp
const auto routing = SearchAssistantRouter::decide(
    m_lastBaselineSearchResult, assistantReady);
if (!routing.shouldInvoke(assistantReady)) {
    // 保留首轮结果，不启动本次模型调用。
    return;
}
```

### 2. 查询计划 V2

- 新响应协议名：`cinevault_search_plan_v2`；
- 删除模型日期字段，日期继续由本地 Qt 规则锁定；
- 增加最多两条 `semantic_variants`；
- 增加最多六个 required/optional/excluded `lexical_groups`；
- 增加 `same_asset` / `same_frame` 共现范围；
- 实体最多四个，输出上限从 384 降至 256 tokens；
- V1 仍可解析；新缓存键升级为 `v6`；
- required 词组必须能在原文或本地显式实体中找到依据；
- excluded 词只有原文明确出现时才生效；
- 模型语义变体权重最高 0.85，不能压过原始语义查询。

### 3. 分组词项和多语义召回

修改前：

```text
女人 OR 女性 OR 牛仔裤 OR 丹宁裤 OR 红色
```

修改后：

```text
(女人 OR 女性)
AND (牛仔裤 OR 丹宁裤)
AND 红色
```

- 原始关键词和原始 BGE 查询始终保留；
- Qwen语义变体独立执行 BGE，再按权重合并；
- excluded 词目前只施加 `-0.20` 排序惩罚，不危险地硬删除候选；
- 词项覆盖评分按概念组计算，未命中的同义词不再错误降低覆盖率。

### 4. 加权 RRF 与首轮保护

- 首轮与增强轮按素材、帧或文件夹主键融合；
- 双路共同命中累加两侧排名和证据；
- 首轮关键词、OCR、同帧和结构化属性证据使用保护权重；
- 增强轮仅有弱语义证据的新候选降权；
- 保留增强为空和结果域改变时完全回退；
- 新增增强新增数、双路共同命中数和首轮保留数统计。

### 5. 缓存、超时和模型生命周期

- 输入搜索或打开快捷搜索时才触发 GPU 预热；
- 应用普通启动不再无条件加载模型；
- `--search-assistant-startup-probe` 仍显式触发预热；
- 模型交互超时改为 3 秒，首轮不等待；
- 成功计划缓存从 64 条升级到 256 条，使用会话内7天有效期和近似LRU顺序；
- 相同进行中请求继续去重；
- 失败查询抑制120秒，避免连续重试；
- 默认无搜索操作卸载时间从60分钟改为30分钟；
- 设置页文案改为“打开搜索或输入查询时智能加载”。
