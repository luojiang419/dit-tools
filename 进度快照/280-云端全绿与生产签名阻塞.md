### 1. QML 门禁回归修复

云端 Run `29556271973` 报告 734 条诊断，超过 731 基线。精确对比确认新增 3 条全部来自 `QuickSearchWindow.qml` 筛选按钮嵌套对象跨 Repeater delegate 边界读取根窗口色值。

修改前：

```qml
color: filterButton.selected
    ? root.quickSelected
    : (filterButton.hovered ? root.quickSurfaceHover : root.quickSurface)
border.color: filterButton.selected ? root.quickSelectedLine : root.quickLine
```

修改后：

```qml
readonly property color fillColor: filterButton.selected
    ? "#2A3039"
    : (filterButton.hovered ? "#252B35" : "#20242C")
readonly property color outlineColor: filterButton.selected ? "#4B5563" : "#303640"
readonly property color labelColor: filterButton.selected ? "#F4F7FB" : "#A0A8B4"
```

嵌套 `background` 和 `contentItem` 仅读取 `filterButton` 自身属性。云端诊断恢复为 731。
