## 已完成内容

### 1. 概念图式 Web UI

修改文件：

- `dit-tools-src/cinevault-pro/resources/websearch/index.html`
- `dit-tools-src/cinevault-pro/resources/websearch/styles.css`
- `dit-tools-src/cinevault-pro/resources/websearch/app.js`

修改前：结果项为纯文字卡片，空态的清除按钮在部分浏览器样式下错误显示。

修改后：

- 空态只保留概念图式的居中搜索框，不显示标题文字。
- 搜索框采用液态玻璃、顶部高光、浅色/暗色自适应和明显的长投影。
- 输入关键词后搜索框上移，结果面板展开为概念图中类似的深色/浅色玻璃列表。
- 结果项加入固定比例缩略图、素材类型、文件名、摘要、路径和命中原因。
- 结果很多时结果面板内部滚动，页面本身不横向溢出。
- 增加清除按钮；补充 `[hidden]` 规则，保证空态不显示清除图标。
- 缩略图加载失败时自动回退到统一占位图标。

### 2. 缩略图 HTTP 代理

修改文件：

- `dit-tools-src/cinevault-pro/src/application/websearch/WebSearchService.h`
- `dit-tools-src/cinevault-pro/src/application/websearch/WebSearchService.cpp`

修改前：搜索结果只返回软件电脑上的本地缩略图路径，局域网浏览器无法读取该路径。

修改后：

- 搜索结果新增相对 `thumbnailUrl`。
- 新增 `GET /api/thumbnail?kind=asset&key=...`，读取数据库登记的素材缩略图。
- 新增 `GET /api/thumbnail?kind=frame&key=...&frame=...`，读取视觉分析帧图。
- 对 key、类型和帧号做参数校验，只从数据库查询到的素材/帧路径提供图片。
- 使用文件实际 MIME 类型返回 JPEG、PNG 等图片内容。
- 显式完整解码 URL 参数，兼容素材 key 中包含冒号的情况。
