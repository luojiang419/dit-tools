# 281 - 任务详情滚动与扫描解析类型修复

## 本轮目标

1. 修复任务页面右侧任务详情栏无法浏览超出窗口内容的问题。
2. 修复磁盘卷扫描中的 SQLite 锁竞争，并让被独占或无权限读取的文件自动跳过解析而不拖垮整卷扫描。
3. 图片、视频保持默认空闲解析；文档与 PSD/PSB 改为默认关闭的可选解析类型，并在设置保存后立即应用于空闲队列。
4. 版本自动递增并生成可验证安装包。

## 已完成内容

### 1. 任务详情栏滚动

- 文件：`dit-tools-src/cinevault-pro/src/ui/qml/components/JobProgressInspectorPane.qml`
- 给详情 `ScrollView` 显式设置纵向内容高度，并绑定内部详情列的隐式高度。

修改前：

```qml
ScrollView {
    Layout.fillWidth: true
    Layout.fillHeight: true
    ColumnLayout { width: detailScroll.availableWidth }
}
```

修改后：

```qml
ScrollView {
    contentWidth: availableWidth
    contentHeight: detailColumn.implicitHeight
    ColumnLayout { id: detailColumn; width: detailScroll.availableWidth }
}
```

### 2. 扫描锁与权限处理

- 文件：`src/core/scan/ScanEngine.cpp`
  - 读取下一目录后主动结束查询游标。
  - 将目录枚举和实际文件打开探测移到写事务外。
  - 使用 `QFile::open(QIODevice::ReadOnly)` 区分“权限属性可读”和“当前确实能打开”。
  - 其他聚合查询在后续写事务前主动 `finish()`。
- 文件：`src/application/MaterialCatalogSyncService.cpp`
  - 同步素材时结合 `asset_file.is_readable` 计算可用性；不可读素材不进入后续解析链路。
- 文件：`tests/unit/ImportServiceLegacyRescanTest.cpp`
  - 新增 Windows 独占文件回归：锁定时扫描成功且记为不可读；解锁重扫后恢复可读。

修改前：扫描器仅依赖 `QFileInfo::isReadable()`，并在数据库写事务中枚举磁盘。

修改后：写事务外实际打开文件，失败记录 `is_readable = 0`；扫描继续，后续解析自动跳过，解锁后可通过重扫恢复。

### 3. 文档与 Adobe 文件可选解析

- 文件：`src/infrastructure/config/AppSettings.*`
  - 新增持久化设置 `documentAutoAnalysisEnabled` 与 `photoshopAutoAnalysisEnabled`，默认均为 `false`。
- 文件：`src/ui/viewmodels/SettingsViewModel.*`、`src/ui/qml/components/SettingsPage.qml`
  - 新增“文档”和“PSD 文件（Adobe 图片文件）”两个默认关闭的开关。
  - 保存应用后写入设置并通知后台队列重新评估。
- 文件：`src/application/BackgroundMaintenanceCoordinator.*`、`src/app/AppContext.cpp`
  - 图片和视频始终属于默认空闲解析队列。
  - 文档/字幕只在文档开关开启时进入队列。
  - PSD/PSB 只在 Adobe 文件开关开启时进入队列。
- 文件：`src/application/VideoAnalysisService.cpp`
  - PSD/PSB 先通过 FFmpeg 解码为项目缓存 JPG，再复用现有视觉解析链路。

默认行为前后对比：

| 类型 | 修改前 | 修改后 |
| --- | --- | --- |
| 图片 | 自动解析 | 自动解析 |
| 视频 | 自动解析 | 自动解析 |
| 文档/字幕 | 自动解析 | 默认仅索引，开关开启后空闲解析 |
| PSD/PSB | 无独立可选策略 | 默认仅索引，开关开启后转 JPG 空闲解析 |
