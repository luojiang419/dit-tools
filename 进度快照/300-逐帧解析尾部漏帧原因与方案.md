## 具体修改的代码前后对比

本轮没有修改源代码。设计中的核心改动如下。

### 当前计划

```cpp
for (int zeroBased = 0; zeroBased < count; zeroBased += interval) {
    numbers.append(zeroBased + 1);
}
```

### 推荐计划

```cpp
for (int zeroBased = 0; zeroBased < count; zeroBased += interval) {
    numbers.append(zeroBased + 1);
}
if (!numbers.isEmpty() && numbers.last() != count) {
    numbers.append(count);
}
```

同时要求 `FFmpegAdapter::extractFrames()` 直接复用
`VisualAnalysisMetadata::plannedFrameNumbers()`，不再自行维护另一套 `% interval` 规则。

### 当前帧时间

```cpp
{QStringLiteral("timestampLabel"), Formatters::formatDuration(frame.timestampMs)}
```

`formatDuration()` 会把 20.750 秒截断为 `0:20`，并把合法的 0ms 显示为“未知时长”。

### 推荐帧时间

新增 `Formatters::formatFrameTimestamp()`：

```text
0ms -> 0:00.000
20750ms -> 0:20.750
```
