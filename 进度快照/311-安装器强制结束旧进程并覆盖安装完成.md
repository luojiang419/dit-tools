## 根因

旧安装器在 `InitializeSetup()` 阶段就执行 `taskkill /F /T /IM CineVault.exe`。该阶段可能还没有完成 Inno Setup 的管理员提权，导致结束旧版进程失败，安装器随后提前中止。

## 修改内容

文件：`installer/windows/cinevault.iss`

### 修改前

```pascal
function InitializeSetup(): Boolean;
begin
  if ShouldForceStopCineVaultProcesses() then
    Result := StopCineVaultProcesses('setup initialization')
  else
    Result := True;
end;
```

### 修改后

```pascal
function InitializeSetup(): Boolean;
begin
  { Do not terminate before UAC elevation. }
  Result := True;
end;
```

实际强制结束统一放在提权后的 `PrepareToInstall()`：

- `taskkill.exe /F /T /IM CineVault.exe`
- PowerShell `Get-Process -Name CineVault | Stop-Process -Force` 作为兜底
- 最多重试 12 次，并等待进程从任务列表消失
- 每次执行结果写入安装日志
- 进程仍无法结束时才提示安装失败
- 删除 `wpReady` 阶段的阻断式清理，避免在未提权阶段误判失败

卸载初始化继续使用同一套强制结束逻辑。
