# 323 - v0.1.203 视频候选帧误筛修复

- 时间：2026-08-03
- 当前模块：素材管理中心视频抽帧质量筛选

## 已完成

1. 修复正常实拍视频被全部判定为“清晰度不足”的问题。
2. 将当前相邻像素亮度梯度算法对应的默认最低清晰度从 `0.08` 校准为 `0.01`。
3. 增加旧设置迁移：已保存且等于旧默认值 `0.08` 的配置，会在 v0.1.203 首次启动时自动改为 `0.01`。
4. 更新请求模型、视频分析服务和设置视图模型的回退默认值，避免任意入口重新使用旧阈值。
5. 回归测试覆盖新默认值、旧值迁移，以及低对比度但合格候选帧的抽取。
6. 生成并校验 Windows 安装包 `v0.1.203`。

## 关键代码前后对比

- 修改前：`minimumSharpness` 的默认值与设置默认值均为 `0.08`。实测两个正常广告视频的清晰度范围为 `0.0036–0.0321`，全部低于阈值，导致候选帧在视觉接口调用前被删除。
- 修改后：默认值统一为 `0.01`，可保留实拍视频中的合格帧；曝光和感知哈希去重规则保持不变。

- 修改前：已经持久化到用户配置中的 `0.08` 不会因代码默认值变化而更新。
- 修改后：`AppSettings` 创建时识别旧默认值并持久化迁移到 `0.01`。
