# 299-语义索引手动立即执行与自动静默完成

## 已完成内容

本轮完成方案 A：保留自动空闲索引，同时增加手动立即执行，并让自动过程对前台页面真正无感。

1. 自动语义索引在系统未空闲时仅保留待办，不再提前启动线程或发出进度信号。
2. 系统进入空闲后，通过 `becameIdle` 事件自动唤醒待办。
3. 新增 `scheduleImmediateFullSync()`，手动任务跳过空闲条件并采用前台资源优先级。
4. 素材中心新增“立即更新语义索引”按钮。
5. 删除原语义索引进度横幅、转圈、进度条和百分比。
6. 搜索状态不再显示“语义索引正在后台更新”。
7. 新增调度与 QML 契约回归测试。
8. 应用版本由 `0.1.186` 递增至 `0.1.187`。
9. 已完成正式构建、全量测试、启动探针和安装包生成。

## 具体修改的代码前后对比

### 自动等待

修改前：

```cpp
emit synchronizationProgress(0, 0, QStringLiteral("正在分页收集全部语义索引文档"));
heavyIoLease = workCoordinator->acquire({
    IndexingWorkCoordinator::Resource::HeavyIo,
    IndexingWorkCoordinator::Priority::Background,
    true,
    workGeneration});
```

修改后：

```cpp
if (!immediateFullSync
    && m_workCoordinator
    && !m_workCoordinator->isSystemIdle()) {
    m_debounceWindow.invalidate();
    return;
}
```

自动任务未满足空闲条件时不进入运行态、不发 UI 信号。

### 手动执行

修改前：无手动语义索引入口。

修改后：

```cpp
void SearchDocumentSyncService::scheduleImmediateFullSync()
{
    m_pendingFullSync = true;
    m_pendingImmediateFullSync = true;
    m_pendingCatalogChanges.clear();
    m_pendingAnalysisVideoKeys.clear();
    schedulePendingWork();
}
```

### 前台页面

修改前：`MaterialCenterWorkspace.qml` 含 `semanticIndexing` 可见性横幅和 `ThemedProgressBar`。

修改后：

```qml
ActionButton {
    text: "立即更新语义索引"
    enabled: viewModel && !viewModel.semanticIndexing
    onClicked: if (viewModel) viewModel.updateSemanticIndexNow()
}
```

原索引状态横幅已整体删除。
