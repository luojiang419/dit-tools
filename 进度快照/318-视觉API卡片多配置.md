## 关键代码前后对比

### 配置持久化

修改前：`AppSettings` 只保存 `visionBaseUrl`、`visionApiKey`、`visionModel` 三个单配置字段，密钥使用单一 Windows 凭据目标。

修改后：新增 `VisionApiConfig` 列表和默认卡片 ID。每张卡包含 ID、名称、Base URL、模型与 API Key；非敏感字段序列化到 `materialCenter/visionApiConfigs`，密钥按卡片 ID 保存在独立 Windows 凭据目标。读取旧设置时会自动生成“默认配置”卡片，不丢失原 URL、模型或密钥；首次保存后完成迁移并删除旧字段。

### 运行时默认项

修改前：素材解析直接使用唯一的 URL、密钥和模型。

修改后：兼容访问器 `visionBaseUrl()`、`visionApiKey()`、`visionModel()` 自动读取默认卡片，因此 `VideoAnalysisService` 无需改动即可使用选中的默认接口。删除默认卡片时自动回退到剩余列表第一张卡片。

### 设置页

修改前：视觉解析区域显示 Base URL、API Key、模型名三行字段。

修改后：参照 `pond5_clip_manager` 的视觉模型区改为卡片网格：单击卡片选择默认接口，卡片展示名称、模型、地址和“当前使用”标识；可添加、编辑、删除卡片（至少保留一张），弹窗内可显示/隐藏 API Key 并单独测试当前选中卡片。选择与编辑都保留在草稿中，点击“保存并应用”后才影响解析服务。
