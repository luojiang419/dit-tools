## 已完成内容

报表页面已将原来固定导出的内容拆分为 8 个独立选项：

1. 封面与项目信息
2. 项目摘要
3. 素材源与扫描概览
4. 格式分布
5. 视频帧缩略图索引
6. 视频元数据明细
7. 音频元数据明细
8. 文件夹树状图

所有选项默认勾选，保证老用户升级后输出不变；取消勾选后，预览和最终 PDF 同时移除相应区块。勾选结果写入 `QSettings` 的 `report/enabledSections`，重启应用后恢复。

## 修改模块与前后对比

### 导出请求和文档模型

文件：

- `dit-tools-src/cinevault-pro/src/core/report/ReportModels.h`
- `dit-tools-src/cinevault-pro/src/application/ReportExportService.h`
- `dit-tools-src/cinevault-pro/src/application/ReportExportService.cpp`

修改前：导出请求没有内容选择，渲染器始终生成全部页面。

修改后：`ReportSectionOptions` 随 `ReportExportRequest` 传入 `ReportDocument`，PDF 和预览共用同一份选择。

```cpp
struct ReportSectionOptions {
    bool cover = true;
    bool summary = true;
    bool sourceOverview = true;
    bool formatDistribution = true;
    bool thumbnailIndex = true;
    bool videoMetadata = true;
    bool audioMetadata = true;
    bool folderTree = true;
};
```

### PDF 渲染

文件：`dit-tools-src/cinevault-pro/src/core/report/ReportRenderEngine.cpp`

修改前：固定调用封面、摘要、缩略图、视频元数据、音频元数据、文件树。

修改后：每个已勾选区块才创建页面；摘要、素材源概览、格式分布已分离。即使用户取消全部选项，也会生成一页明确提示，而不会产生空白或损坏 PDF。
