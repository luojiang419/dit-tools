## 任务目标

以可追溯证据解释故障机制，制定能从数据流、调度、存储和 UI 契约消除反复回归的实施方案，避免继续叠加阈值和定时器补丁。

## 当前项目现状

Windows Qt 6 / C++ / QML / SQLite / FFmpeg 桌面应用，历史上已引入分页、协调器、增量同步和尾帧逻辑；近期未提交改动包含新的候选帧筛选及视觉 API 接入。实际覆盖程度以本轮代码检查为准。

## 技术方案

- 按调用链检查执行线程、数据规模、SQL 复杂度、通知放大、队列容量、取消与恢复。
- 分离抽样计划、解码成功、质量筛选、视觉解析和展示覆盖，避免把不同阶段的遗漏混为一谈。
- 采用“代码确认 / 最小复现 / 条件性风险 / 未验证”的证据标注。
- 设计可渐进迁移、可回滚、保留已解析数据的目标架构及性能验收门禁。
