## 任务目标

## 当前项目现状

- Qt 6 / C++ / QML / SQLite / FFmpeg Windows 桌面应用。
- 扫描枚举、媒体元数据和全局素材同步已有分页基础。
- 素材中心仍有同步查询/详情/拼图路径；任务进度仍可能在 UI 线程写库。
- 新视频策略采用 FFmpeg 过滤器生成候选后全片质量/哈希筛选，缺少独立时间覆盖记录。
- 搜索文档有增量队列，但失败消费缺少可靠重放；向量索引每个小批次保存完整文件。

## 技术方案

- 正确性契约先于实现：每个已复现问题先补测试，再修改代码。
- 前台只提交请求和应用有限结果；数据库、解码、索引和拼图进入各自工作执行器。
- 抽帧按时间窗口规划，必保首尾锚点；相似画面可复用分析，但不删除时间节点。
- 重建写新代并在验收后切换，失败保留当前有效代。
- 写入按数据库串行化、短事务；调度等待不占执行线程。
- 搜索消费采用持久水位/失败重放；向量索引采用批次末统一发布并逐步演进为快照。

## 验收标准

- 盘符根和普通目录变化均产生正确脏路径。
- 视频最后可解码时刻有覆盖记录，末尾重复画面不从时间线上消失，输出尺寸符合请求。
- 重建失败仍可读取上一代解析；设置变化以完整计划指纹决定重采样/重分析。
- 素材中心搜索、详情、拼图和任务写库不在 UI 线程执行重型 I/O；帧详情为数据库分页并使用虚拟化视图。
- 扫描计数避免按受影响目录重复全源扫描；writer lease 与事务生命周期一致。
- 搜索增量失败可重放；小批量更新不反复保存整份向量索引。
- 相关单元测试、压力测试、完整构建和启动验收真实通过。
