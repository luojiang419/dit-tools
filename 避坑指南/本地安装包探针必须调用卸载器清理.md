# 本地安装包探针必须调用卸载器清理

## 问题

`test_installer_startup.ps1` 以前在静默安装和启动验证后直接删除安装目录。Inno Setup 已经写入系统卸载注册项和开始菜单快捷方式，直接删目录不会撤销这些系统状态，会留下指向不存在临时目录的卸载项与快捷方式。

## 原因

文件系统清理不等于安装事务回滚。Inno Setup 的卸载日志、注册表项和快捷方式只能由生成的 `unins000.exe` 正确清理。

## 修复

- 安装探针增加 `/NOICONS`，避免测试创建快捷方式。
- 启动验证后静默运行 `unins000.exe`。
- 检查卸载退出码并设置超时。
- 只有卸载器完成系统状态清理后，才删除未被卸载日志跟踪的 Qwen 哨兵残留目录。
- Inno Setup 的临时卸载进程可能在主进程返回后短暂持有 `unins000.exe`，残留目录清理需有限重试等待句柄释放。

## 后续规则

- 本地或 CI 运行安装探针时必须保留 `-AllowInstallerRegistration` 显式确认。
- 不得用 `Remove-Item` 代替卸载器清理已注册的安装。
- 若测试中断，先核对卸载项和快捷方式是否指向本次临时目录，只清理精确匹配的测试残留，不能删除真实用户安装项。
