# 本地语义搜索日期词必须先转为范围条件

日期：2026-07-31

## 现象

搜索“去年的视频”时，结果同时包含 2025 和 2026 的视频。

## 原因

本地向量搜索只理解语义相似度，不会自动把“去年”推导成时间范围。若自然语言解析器没有识别日期词，向量召回就会把不同年份的相似素材混在一起。

## 正确方案

1. 先由 `NaturalLanguageQueryParser` 提取日期约束。
2. 将“去年”转换为上一自然年的起止日期。
3. 将日期词从语义文本中移除，避免它参与内容相似度。
4. 在 SQL 候选查询阶段用 `capture_date` 过滤，缺失时才回退 `modified_at`。
5. 在 Web 页面显示日期范围和实际日期来源，便于发现元数据缺失。

## 当前支持

- 今天、昨天、前天
- 今年、去年、前年
- 本年度、上年度、上一年
- 明确年份，例如 `2025年`
- 完整日期、最近 N 天、周/月相对范围
