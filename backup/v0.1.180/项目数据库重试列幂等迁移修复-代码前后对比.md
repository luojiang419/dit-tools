# 项目数据库重试列幂等迁移修复 - 代码前后对比

## 背景

真实项目 `D:\data\影视管家\服装\project.cvdb` 复现：

- `schema_version = 9`
- `media_metadata` 仍是旧列：`asset_id, probe_status, media_type, container, duration_ms, bit_rate, raw_json, error_message, updated_at`
- 新版任务查询已依赖 `next_retry_at / retry_count / retry_policy_version / failure_kind / last_attempt_at`
- 打开项目后报错：`no such column: next_retry_at`

## 修改文件

- `dit-tools-src/cinevault-pro/src/infrastructure/db/DatabaseManager.cpp`
- `dit-tools-src/cinevault-pro/tests/unit/FolderDatabaseMigrationTest.cpp`

## 修复前

`ensureMediaSchemaCompatibility()` 会先创建依赖新增列的索引，再补列：

```cpp
const QStringList statements = {
    QStringLiteral("CREATE INDEX IF NOT EXISTS idx_media_metadata_retry "
                   "ON media_metadata(probe_status, next_retry_at, retry_policy_version, asset_id);")
};

if (!executeBatch(db, statements, errorMessage)) {
    return false;
}

return ensureColumns(db, QStringLiteral("media_metadata"), {...}, errorMessage);
```

如果旧表还没有 `next_retry_at`，索引创建先失败，后面的 `ensureColumns()` 根本没有机会执行。

`ensureEmbeddedMetadataSchemaCompatibility()` 也有同类风险：`idx_embedded_metadata_retry` 在补列前创建。

## 修复后

先创建不依赖新增列的表和旧索引，再补齐列，最后创建 retry 索引：

```cpp
if (!executeBatch(db, statements, errorMessage)) {
    return false;
}

if (!ensureColumns(db, QStringLiteral("media_metadata"), {...}, errorMessage)
    || !ensureColumns(db, QStringLiteral("media_stream"), {...}, errorMessage)
    || !ensureColumns(db, QStringLiteral("thumbnail"), {...}, errorMessage)) {
    return false;
}

return executeBatch(db,
                    {QStringLiteral("CREATE INDEX IF NOT EXISTS idx_media_metadata_retry "
                                    "ON media_metadata(probe_status, next_retry_at, retry_policy_version, asset_id);"),
                     QStringLiteral("CREATE INDEX IF NOT EXISTS idx_thumbnail_retry_schedule "
                                    "ON thumbnail(status, next_retry_at, retry_policy_version, asset_id);")},
                    errorMessage);
```

`embedded_metadata` 同步改为：

```cpp
if (!executeBatch(db, statements, errorMessage)
    || !ensureColumns(db, QStringLiteral("embedded_metadata"), {...}, errorMessage)) {
    return false;
}
return executeBatch(db,
                    {QStringLiteral("CREATE INDEX IF NOT EXISTS idx_embedded_metadata_retry "
                                    "ON embedded_metadata(status, next_retry_at, retry_policy_version, asset_id);")},
                    errorMessage);
```

## 新增测试

`FolderDatabaseMigrationTest::projectMetadataRetryColumns_repairFromV9AndCurrentSchema()`

覆盖：

- `schema_version = 9` 但 `media_metadata / embedded_metadata` 仍为旧表；

- `idx_media_metadata_retry / idx_embedded_metadata_retry / idx_thumbnail_retry_schedule` 均在补列后创建。
