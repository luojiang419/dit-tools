# Qwen3 0.6B 智能搜索优化实现方案

## 一、目标与边界

本方案继续使用内置 `Qwen3-0.6B-Q8_0.gguf`，不扩大模型参数量。优化重点不是让模型直接搜索素材，而是让它在本地规则和首轮检索无法可靠处理时生成受约束的查询计划。

固定边界：

- 日期、类型、项目范围、用户显式结果域和 OCR 继续由本地规则锁定；
- Qwen 只接收查询文字与本地解析摘要，不接收路径、数据库行、图片或视频；
- 首轮 FTS5、结构化事实和 BGE 搜索立即执行，不等待模型；
- 模型失败、超时、低置信度、改变结果域或产生空结果时保留首轮结果；
- GPU 不可用时停用模型增强，不回落到 CPU。

## 二、优化后的搜索链路

1. 本地解析器提取日期、类型、结果域、OCR、语义文本和显式实体。
2. FTS5、结构化事实和原始 BGE 查询产生首轮结果并立即展示。
3. `SearchAssistantRouter` 根据查询复杂度和首轮可靠性选择：
   - `Skip`：确定性查询或高可靠直接证据；
   - `ReadyOnly`：可靠性灰区，仅使用已经就绪的模型；
   - `Required`：首轮无结果、多实体、关系、否定、并列或模糊查询。
4. Qwen 输出查询计划 V2。
5. 搜索引擎使用同义词组和语义变体执行第二轮多路召回。
6. `SearchResultFusion` 使用加权 RRF 融合首轮与增强轮，并保留首轮强证据。

## 三、查询路由

### 不调用模型

- 空查询；
- 纯日期、类型、文件夹或结果域查询；
- 精确文件名、扩展名、路径和明确 OCR；
- 首轮可靠性不低于 `0.82` 且具有关键词、OCR 或结构化直接证据。

### 必须调用模型

- 多个显式实体；
- 穿着、拿着、站在、旁边等关系；
- 不要、排除、不包含等否定；
- 同时、并且、或者等组合；
- 首轮没有结果；
- 首轮可靠性低于 `0.68` 或可靠性评估明确要求助手。

### 可靠性灰区

可靠性在 `0.68–0.82` 之间时使用 `ReadyOnly`。模型已就绪则补充理解；模型未就绪时不让首轮结果等待冷启动。

## 四、查询计划 V2

V2 删除模型日期字段，新增：

- `semantic_variants`：最多两条规范化语义查询，权重不超过 `0.85`；
- `lexical_groups`：最多六个 required、optional 或 excluded 概念组；
- `cooccurrence`：none、same_asset 或 same_frame；
- `ambiguities`：模型识别但不应擅自确定的歧义。

required 概念组必须至少包含一个能在用户原文或本地显式实体中找到依据的词。excluded 词必须在用户原文中明确出现。模型虚构的颜色、材质和属性不能成为硬条件。

V1 计划仍可解析，但新模型请求只使用 V2，缓存键同步升级，避免旧计划与新协议混用。

## 五、多路召回

- 原始关键词和原始 BGE 查询始终保留；
- required 词组使用“组内 OR、组间 AND”；
- optional 词组只增加召回和评分；
- excluded 词当前只降低排序，不直接删除候选；
- 每条 Qwen 语义变体独立执行 BGE，按模型权重折减后与原始语义分数合并；
- 完整结构化事实继续验证同帧实体及显式属性。

## 六、融合排序

首轮和增强轮以素材、帧或文件夹主键去重。融合使用偏移量为 60 的加权 RRF：

- 首轮关键词、OCR、同帧或属性验证证据权重最高；
- 两轮共同命中的候选累加两侧排名和证据；
- 模型仅有单路弱语义的新候选降低权重；
- 增强为空或结果域变化时完全返回首轮；
- 每次融合统计增强新增、双路共同命中和首轮保留数量。

## 七、性能与生命周期

- 搜索输入或打开快捷搜索时触发 GPU 预热，不再应用启动后无条件常驻；
- 启动探针会显式触发搜索意图，保留真实 GPU 验收能力；
- 交互查询模型超时为 3 秒，首轮结果不等待；
- 模型最大输出由 384 降至 256 tokens；
- 成功计划缓存上限 256 条，会话内有效期 7 天；
- 相同进行中请求去重；
- 失败查询抑制 120 秒，避免连续重试；
- 默认无搜索操作 30 分钟卸载，可继续使用 5–1440 分钟设置。

## 九、验收指标

- 确定性和高可靠简单查询不调用 Qwen；
- 无结果、多实体和复杂关系查询调用 Qwen；
- 本地硬条件覆盖率保持 100%；
- 模型失败或超时不清空首轮结果；
- 原始 BGE 查询权重始终高于模型语义变体；
- 强首轮证据不被弱模型语义候选压制；
- 首轮 UI 路径不等待模型；
- 热模型调用在 3 秒内完成或回退；
- GPU 缺失、模型缺失和助手关闭时基础搜索继续可用。

## 十、验证状态

源码、单元测试用例和静态契约已经补充。本轮根据项目约定未进行本地完整编译、提交、推送或发布；真实 Qwen V2 输出、Release 构建和全量 CTest 需要在后续明确的云端编译或发布流程中完成。
